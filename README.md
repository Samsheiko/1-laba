## Задание 1







### Задача 1







### Текст задачи








#### Сформировать список из значений 1 и 0 по принципу: 0 — если очередное введенное число
нечетное, 1 — в противном случае.







### Алгоритм решения



######



#### Алгоритм работы программы начинается с получения входного значения от пользователя через консоль, которое определяет общее количество итераций для обработки чисел. Далее вводится количество чисел. Для каждого введенного числа выполняется проверка на четность с помощью операции остатка от деления на два: если остаток равен нулю, число признается четным и в формируемую коллекцию через ключевое слово yield передается строковое значение «1», в противном случае передается «0». Все накопленные значения автоматически собираются в единый итоговый список.

# Задание 2







### Задача 1



###



### Текст задачи







#### Сформировать список из четных цифр числа.







### Алгоритм решения







#### Алгоритм работает по принципу рекурсивного обхода числа от конца к началу с последующей сборкой списка в прямом порядке. Сначала программа считывает введенное число и передает его в функцию, которая проверяет, является ли оно однозначным. Потом если число меньше десяти, то оно проверяется на четность. При положительном результате цифра возвращается в виде элемента списка, иначе возвращается пустой список. После возврата из рекурсии текущая последняя цифра проверяется на четность и если условие выполняется, она добавляется в хвост уже сформированного списка. В итоге все четные цифры объединяются в единую последовательность.
